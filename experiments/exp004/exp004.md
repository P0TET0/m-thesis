exp004：電気伝導率に関するフォルダ

plot_sige_ec_by_composition_source_colored：SiGe の電気伝導率曲線を組成ごとに出典別で色分け表示し、対応表 CSV や HTML も出力できるスクリプト。

plot_sige_ec_by_composition：SiGe の電気伝導率曲線を組成ごとにまとめてプロットし、必要に応じて分割 CSV も保存するスクリプト。

curve_master.csv：入力 CSV の 1行 = 1曲線 という構造を保ったまま、以下を追加。

    追加列:
    - curve_id
    - n_points
    - sigma_source
    - is_valid_curve

    仕様:
    - curve_id は各曲線を一意に識別するID
    - 作り方は DOI, sample_id, figure_id, Index を連結した文字列でよい
    - n_points は x_list の点数
    - sigma_source は以下のルール
      - prop_y に conductivity を含む → original_conductivity
      - prop_y に resistivity を含む → converted_from_resistivity
      - それ以外 → unknown
    - is_valid_curve は以下の条件を満たすと True
      - prop_x が Temperature
      - x_list と y_list の長さが一致
      - 点数が 2 点以上

    注意:
    - x_list, y_list は CSV 内で文字列化されている可能性があるので、安全に list に戻す処理を実装してください
    - ast.literal_eval を優先し、失敗時は空配列にしてください
    - エラーで落ちにくい実装にしてください

    出力ファイル:
    - curve_master.csv

point_master.csv：curve_master.csv を入力として、1行 = 1温度点 に展開した CSV を作る。

    出力列:
    - curve_id
    - DOI
    - sample_id
    - figure_id
    - composition
    - si_frac
    - ge_frac
    - point_index_in_curve
    - curve_n_points
    - point_weight
    - T_K
    - sigma
    - log10_sigma

    仕様:
    - x_list / y_list を1点ずつ展開する
    - point_index_in_curve は 0 始まり
    - curve_n_points はその曲線の総点数
    - point_weight = 1.0 / curve_n_points
    - sigma <= 0 の点は除外
    - log10_sigma = log10(sigma)
    - 欠損や壊れた曲線はスキップしてよい
    - is_valid_curve == True の曲線だけを対象にしてください
