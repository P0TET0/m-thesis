# 係数の基準をそろえた後の問題と閾値の検討

最新の検討では、母材の合金成分を保持してドーパントだけを分類から除くことを目的としています。SiGeのGeを消してSi主体にする案は、その目的に沿いません。役割の判定方法は `host_alloy_dopant_review_ja.md` に記録しています。以下は、主成分分類も含めて検討した過去の閾値案とその問題点です。

`Si0.5Ge0.5` はSiGe混合母材として両元素を残す方針に合意しました。0.5という閾値、他の材料への同率規則の拡張、同率とみなす許容幅は未確定です。この資料は判断材料であり、分類やモデルは変更していません。

現時点では、0.5を全材料に共通するドープ判定の閾値として採用することは勧めません。係数の基準をそろえると表記倍率の問題は解消できますが、少量添加を除く判断と、合金を主成分側へまとめる判断は残ります。Si0.8Ge0.2をSi主体に分類する意図は、後者として扱うと明確になります。

## 同率の例外だけでは防げない問題

| 問題 | 手元の実例・判断への影響 | 対応案（未採用） |
| --- | --- | --- |
| 係数0.5の意味が材料系で違う | Si+Ge=1なら0.5は50%。Bi+Sb=2なら0.5はBi/Sbの合計の25%。同じ数値でも除外する範囲が異なる | どの元素群を分母にした割合かを明示する。全原子の割合とも区別する |
| 3成分以上で母材を構成する | `Ti0.3Zr0.35Hf0.35NiSn` ではTi・Zr・Hfがすべて0.5以下。Tiは他の2元素と同率でもない | 混合占有する元素群を保持する。最大量の元素だけを救済する規則でも不十分 |
| 少ない係数が母材の一部を表す | `Na0.5CoO2` のNaを消すと、ナトリウムコバルト酸化物としての情報が失われる | 母材を構成する元素と、置換・添加成分の候補を区別する。係数が小さいだけで除外しない |
| 境界直前・直後で分類が飛ぶ | 実データに `Bi0.48Sb1.52Te3` と `Bi0.52Sb1.48Te3` がある。0.5では前者だけBiを除く | 境界近傍を別に確認する。同率の許容幅も独立に検討する |
| 母材の決定と係数の基準が相互依存する | 既存分類がBiTe系の `Pb0.997Bi0.003Te` に、旧分類を根拠としたBiTe用の基準を当てると、誤った母材候補を固定しかねない | 旧分類を正解として使わず、複数の母材候補と組成整合性を確認する。曖昧なものは保留する |
| 組成だけでは相・構造を確定できない | 同じ公称組成でも、合成条件によって固溶・析出・複数相の状態が異なる | 論文・試料情報を優先する。組成由来の分類と構造を確認した分類を区別する |
| 複合材料の比率と原子比が混在する | 手元にPEDOT:PSSとBi2Te3の混合量をwt.%で記載した試料がある。重量比を式中の係数として扱えない | 複合材料は別処理とする。文章、変数、単位付き表記を黙って数値化しない |

Ti–Zr–Hfの例は、手元に同じ組成表記で10試料あり、直近のDF図にも4試料含まれます。原論文はTi・Zr・HfによるMサイトの置換を扱うハーフホイスラー材料の研究です。原論文ではHfに富む領域も報告されており、組成式だけから単一相と判断できない例でもあります。[Appelらの原論文](https://link.springer.com/article/10.1007/s11664-012-2249-5)

Naの例は手元に2試料あり、収録元はNa含有量x=0.5と0.7の層状コバルト酸化物の研究です。Naの係数0.5を、そのままドーパントである証拠にはできません。[著者所属機関の論文情報](https://khu.elsevierpure.com/en/publications/enhanced-power-factor-of-epitaxial-layered-cobaltite-nax-coo2-thi-2/)

Bi0.5Sb1.5Te3も、研究上は母材として扱われます。例えば、そのSbの一部をTiに置き換える研究では、Bi–Sb–Teの母材とTi添加を区別しています。[Ti添加の原論文](https://pubs.rsc.org/en/content/articlelanding/2019/ra/c8ra09771b)

境界近傍のSi0.49Ge0.51とSi0.50Ge0.50も理論上の問題です。前者がGe主体、後者だけ混合母材となるため、丸めや分析値の違いで分類が変わりえます。ただし今回の手元データでは、Si・Geだけの数値式でSi比率45〜55%に入るものは、50:50を表す2種類の表記だけでした。49:51の実例を確認したという意味ではありません。40:60〜60:40などの幅を設ける場合、その幅は別途根拠と検証を要します。

## 0.5を変えた場合の試算

今回は、手元の全保存試料から、Si・Geだけを含む208試料と、Bi・Sb・Teだけを含みTe/(Bi+Sb)が1.49〜1.51の763試料を選びました。後者の範囲は(Bi,Sb)2Te3付近を調べるための診断条件で、採用済みの分類規則ではありません。他の元素を含むドープ試料はこの表から除いています。

Si+Ge=1、Bi+Sb=2になるように係数をそろえ、少ない側の元素が各閾値以下になる試料を数えました。50:50の組は、この試算では保持しています。

| 係数の閾値（以下を除外） | Si–Ge：208試料中 | Bi–Sb–Te：763試料中 |
| --- | ---: | ---: |
| 0.05 | 30 | 0 |
| 0.10 | 55 | 2 |
| 0.20 | 125 | 8 |
| 0.30 | 146 | 28 |
| 0.50 | 168 | 697 |

この件数は、除外が妥当なドーパントの数でも、分類変更が確定した数でもありません。閾値によって何試料の成分が省略されるかを示します。Si–Geでは50:50の40試料を除く全168試料が、0.5で片側だけになります。Bi–Sb–Teでは0.5付近のBi係数を持つ試料が多いため、0.3から0.5の間で対象が急増します。

比較する分母を合わせると結果も変わります。例えば「Si+GeまたはBi+Sbに占める少数成分の割合が5%以下」なら、Si–Geで30試料、Bi–Sb–Teで2試料です。Bi–Sb–Teの係数0.5はこの割合で25%なので、5%とは大きく異なります。この5%は検討例であり、普遍的なドープ境界ではありません。

## 提案する判定の分け方

1. **材料系と主成分を別々に記録する。** Si0.8Ge0.2は材料系をSi–Ge、主成分をSiとする案です。主成分による比較にはSi主体という区分を使えますが、Geを20%含む合金という情報は残します。Si0.5Ge0.5の主成分区分は合意どおり混合母材とします。
2. **母材の構成元素を数値だけで消さない。** 組成と文献から母材候補を確認し、混合占有や非化学量論組成を保護します。Bi/Sbのような元素群を分母にする割合は、結晶学的なサイト占有を確認した値とは区別して保存します。
3. **少量成分の除外閾値は独立に比較する。** 置換される元素群が確認できる材料では、その群内の1%、2%、5%などを実験条件として比較する案です。これらの値を化学的な定説とは扱いません。置換先や母材が分からない試料は、全原子比への自動切替で確定せず保留します。
4. **閾値の評価には物性予測の誤差だけを使わない。** 母材の正解例に対する分類、混合材料の保持、同一組成比での整合性、保留件数を先に確認します。モデルまで変更する段階では同じ分割で評価し、最終テストデータの成績を見て閾値を選びません。

0.5は、合計を1とした2成分のうちどちらが過半数かを決める境界としては意味があります。しかし、その小さい側をドーパントとみなす根拠にはなりません。今回の目的に合わせるなら、「主成分を選ぶ基準」と「微量添加を分類から除く基準」を別々に検証する方針を推奨します。

## 追加案：除外後の組成を合計1にする

ユーザーから「0.5以下を除き、残った元素の比率の合計を1にして、除いた成分が最初からなかったように分類する」という案が出ました。分類用の組成表現として検討できます。0.5という除外閾値を正式採用したわけではなく、分類・モデルは未変更です。

除外後に残った元素の係数をそれぞれ、残った係数の合計で割ります。係数をa_i、残す元素の集合をRとすると、分類用の比率は b_i = a_i / Σ(j∈R)a_j です。この処理で合計は1になりますが、残った元素どうしの比率と元素集合は変わりません。したがって、前の材料別試算の除外件数も変わりません。現行の元素の有無による分類では、除外後に合計1へ変換する処理自体は分類結果を変えません。

以下は、既に通常の化学式の尺度で記載された例に係数0.5以下の除外を一度だけ適用した計算です。Si0.5Ge0.5は合意した例外として両方保持します。

| 元の表記 | 除外後に合計1へ変換 | 解釈 |
| --- | --- | --- |
| Pb0.997Bi0.003Te | Pb約0.49925、Te約0.50075 | Biを除いてPb–Teの分類に使える。ただし厳密なPb:Te=1:1には戻らない |
| Si0.8Ge0.2 | Si=1 | Si主体という分類用の表現になる |
| Si0.5Ge0.5 | Si=0.5、Ge=0.5 | 合意した混合母材の例外 |
| Bi0.5Sb1.5Te3 | Sb=1/3、Te=2/3 | 元素の組はSb–Teになるが、Sb2Te3の比率2/5・3/5とは異なる |
| Ti0.3Zr0.35Hf0.35NiSn | Ni=0.5、Sn=0.5 | Ti・Zr・Hfの情報は正規化しても戻らない。母材をNi–Snとみなせる根拠にはならない |

「添加元素が存在しない母材組成を復元する」ことと、「除外後の全係数を合計1にする」ことは同じ処理ではありません。例えばBiがSbと同じ元素群の一部を置換していると仮定し、その群の合計2をSbで埋め直すなら、Bi0.5Sb1.5Te3からSb2Te3を作る処理になります。この場合はSbだけを1.5から2に変えており、全体の正規化ではありません。置換される位置と母材の係数が分かる場合に限って検討すべき別の規則です。

除外後の正規化では、除外前の表記倍率の問題も残ります。元表記に直接0.5を当てると、Si0.98P0.02はSi=1になり、同じ比率のSi98P2はSi=0.98・P=0.02になります。Starrydata2のモル比表記に対しては、先に除外判定の尺度をそろえる必要があります。[公式の組成表記説明](https://starrydata.wordpress.com/2018/07/04/save-data-from-papers/)

処理順の候補は「判定用の係数基準をそろえる → 保護対象と除外対象を決める → 除外を一度だけ行う → 残った全元素を合計1にする → 分類」です。正規化後に0.5以下の除外を繰り返しません。全元素が消える試料は正規化できないため保留します。

原組成と除外元素・除外前の量を保存し、正規化した表現は分類用の別項目にします。実測物性は元の添加・置換を含む試料の値なので、組成の表現を変えても無添加材料の実測値にはなりません。DF・ML・FMLで予測を変更する場合も、元の組成情報を削除する判断は分けて扱います。
