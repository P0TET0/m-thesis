Step30 information-rich tau_eff ML evaluation

Purpose
- Step30 is an additional evaluation restricted to samples with richer material information.
- Step30 does not refit tau_eff.
- Step30 does not recalculate sigma, PF, or ZT.
- Step30 uses Step18 target_log_tau_eff_step18 as the objective variable.
- Step30 does not causally prove why ML performance decreases.
- Existing material_system values were all or mostly unknown, so material_system_info_step30 uses existing values when available and otherwise a coarse composition-derived Step30-only fallback. Original columns are not changed.

Interpretation
- Restricting to information-rich samples can improve feature quality, but it also reduces training data size.
- If performance improves, the result supports insufficient information as a candidate contributor to lower ML performance.
- If performance does not improve, tau_eff definition, C(T) construction, data variability, and extrapolation difficulty also need to be considered.
